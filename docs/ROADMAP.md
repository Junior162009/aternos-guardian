# Roadmap

## MVP scaffold
- [x] Mobile dashboard and PWA shell
- [x] Honest unknown state when no status provider is configured
- [x] Local history and server configuration
- [x] Manual start request composer
- [x] Supabase schema with RLS
- [x] Parser unit tests and CI

## Next
- [ ] Select and document a compatible public Bedrock status provider
- [ ] Add Supabase authentication and server CRUD
- [ ] Persist checks from a trusted backend function
- [ ] Schedule backend monitoring with provider-compliant rate limits
- [ ] Add opt-in email/push notifications
- [ ] Add uptime charts based only on actual samples
- [ ] Add end-to-end tests and deployment preview

## Non-goals
No automated Aternos login/clicks, private endpoints, cookies, fake activity, repeated restarts, or promises of permanent uptime.
